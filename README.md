# 🔐 Caesar Cipher – Python Project

## Project Description
Caesar Cipher is a simple encryption and decryption program built using Python. It shifts letters by a given number to encode or decode messages.

## Features
- Encrypt text messages.
- Decrypt encrypted messages.
- Custom shift number.
- Handles spaces and special characters.

## Concepts Used
- Python Functions
- For Loops
- If-Else Statements
- Strings
- Lists and String Indexing
- Modulo Operator
- User Input
